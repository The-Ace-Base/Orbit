# Orbit

**A simple, open chat experience built on Matrix.**

Orbit is a chat application built around the [Matrix protocol](https://matrix.org/). It focuses on making open, decentralized communication feel simple and familiar without putting the underlying protocol in the user's way.

## Why Orbit?

Most chat apps keep communication inside a single platform.

Orbit takes a different approach.

Matrix allows people on different homeservers to communicate through federation, so the network isn't tied to one company or one server.

Orbit is built to make that experience feel like a normal modern chat app.

## Built on Matrix

Orbit uses Matrix for its underlying communication infrastructure.

Matrix provides the protocol for things like:

- Conversations and rooms
- Events and messaging
- Federation between homeservers
- User identities
- End-to-end encryption

Orbit focuses on the interface and experience around that infrastructure.

## Design

Orbit aims to keep things straightforward.

The interface should help you:

- Find conversations
- Send messages
- Navigate your chats
- Manage your account
- Understand what's happening

The protocol can be complicated.

The app doesn't need to be.

## Open communication

Matrix is an open network rather than a single centralized messaging service.

A user on one homeserver can communicate with users on another through federation.

That gives Orbit a different foundation from traditional closed chat platforms.

## Privacy

Orbit relies on Matrix's existing security and encryption mechanisms rather than attempting to create its own cryptography.

Privacy and security are important parts of the platform, while keeping the user experience understandable.

Because, historically, telling developers to "just invent some cryptography" has gone spectacularly well.

## Status

Orbit is currently being developed.

The project is focused on building a clean and practical Matrix client while exploring what a modern chat experience on an open network can look like.

This repository will evolve alongside the project.

## Philosophy

> **Communication should be open.  
> The experience should be simple.**

Orbit is built on Matrix, with the goal of making decentralized communication feel less complicated.
