## ✦ About

Most chat apps keep communication inside a single platform.

**Orbit takes a different approach.**

Orbit is a chat application built around the [Matrix protocol](https://matrix.org/), focusing on making open, decentralized communication feel simple and familiar.

The technology underneath can be complicated.

The experience shouldn't be.

---

## ◉ Why Orbit?

Orbit is built around a simple idea:

> **Communication should be open. The experience should be simple.**

Instead of building another closed messaging ecosystem, Orbit uses Matrix as its communication layer and focuses on the part people actually interact with: the application.

That means keeping the interface clean while letting Matrix handle the underlying network.

---

## ◎ Built on Matrix

Orbit uses Matrix for its underlying communication infrastructure.

Matrix provides the protocol for:

| Capability | Matrix |
|---|---|
| Messaging | ✓ |

| Federation | ✓ |

Orbit builds on top of that foundation rather than attempting to reinvent messaging infrastructure.

Learn more about Matrix:

**[matrix.org](https://matrix.org/)**

---

## ◌ Open by design

Matrix isn't a single centralized messaging network.

Different homeservers can communicate with each other through **federation**, allowing users across different parts of the network to communicate.

Orbit is designed around that open model.

Your chat application shouldn't have to decide which part of the network you're allowed to exist in.

---

## ⌁ Privacy

Orbit relies on Matrix's existing security and encryption mechanisms instead of creating its own cryptographic system.

That's intentional.

Cryptography is one of those areas where "I'll just make my own" is generally followed by a security incident and several uncomfortable conference talks.

Orbit's focus is to make secure communication easier to use without exposing users to unnecessary complexity.

---

## ◇ Design philosophy

Orbit aims to keep the interface:

- **Simple**
- **Clean**
- **Fast**
- **Familiar**
- **Focused**

The protocol shouldn't get in the way of the conversation.

## ⚙️ Project status

> **Orbit is currently in development.**

Features and architecture may change as development continues.

This README intentionally describes the project as it exists rather than promising a futuristic shopping list of features that may or may not survive contact with reality.
